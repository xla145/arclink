# Design and change boundary
No adapter exists. Implement only phase0/prototype as a Rust stdio JSON-RPC client for locked Codex app-server; native schema in phase0/schema is authoritative. Separate stderr, bound framing and waits, correlate request IDs and thread/turn/item IDs. Use a disposable working directory and marker files as execution oracle. Retain sanitized allowlisted samples. Native process identity must invalidate old approvals. No SDK sidecar needed for Codex. Documentation distinguishes interface availability from empirical success. SQLite transactional CAS is the later storage candidate; no daemon in this phase.
