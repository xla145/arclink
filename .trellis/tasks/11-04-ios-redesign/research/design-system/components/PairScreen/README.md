Pairing is the first screen a new user sees: it explains ArcLink in one line and gets them to scan the Mac's QR code.

Centered app icon (88pt, 20pt corner), the title 连接你的 Mac in 26px bold, one sentence of value in `ink-muted`, then three numbered steps as ListRows with `accent` number tiles. The single block primary button 扫描二维码 is pinned to the bottom, with a ghost link for installing the Mac app beneath it.

The scan screen itself keeps its full-bleed camera, corner brackets and torch button; its scan line changes from system green to `brand-teal`, and its failure toast becomes a Banner.
