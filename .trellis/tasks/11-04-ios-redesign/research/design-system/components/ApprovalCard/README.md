The approval card asks you to allow or deny something the agent wants to do, right where it happens in the conversation.

`warning-soft` card, `radius-lg`, `space-4` padding. A heading with a clock icon in `warning` (等待你批准), one sentence of what in `ink`, the command or file target in a `font-mono` well on `surface`, then two equal buttons: 拒绝 (secondary, on `surface`) and 允许 (primary). Tapping the target opens the full approval detail.

Consumer provides agent, project, the request title and target, and both handlers. While a decision is submitting, replace the buttons with a small progress line. The same request also counts in the bell badge on Home.
