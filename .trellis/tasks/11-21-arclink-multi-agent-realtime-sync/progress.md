# Implementation progress

## 2026-11-21: managed-thread foundation

Implemented:

- Transactional schema 1 → 2 migration, stable environment identity, domain tables and constraints.
- Project/Thread persistence with command receipts and events in the same transaction.
- Project-specific access grants; revoke/regrant does not restore old access.
- Managed catalog RPCs over existing ABP, with explicit response bounds.
- Transactionally consistent Thread snapshot and bounded replay reads with environment/cursor validation.
- Typed Rust client/UniFFI methods; regenerated device and simulator libraries and Swift bindings.
- Codex bounded JSONL/public-event normalization, native approval IDs and late-completion fencing.
- Bounded Codex session actor with handshake, request correlation, full-write ACKs, approval decisions and timeout/EOF failure handling.
- Internal server-owned ProcessManager sessions, isolated from remote raw I/O, plus a stdout bridge that handles backpressure and stops the process when the actor closes.
- Durable turn reservation/claim/delivery/completion primitives. A restart fails unsent queued work and quarantines possibly sent work as outcome_unknown; no automatic replay.
- Added authenticated `threads.send`, `threads.interrupt`, `threads.approval` service commands and a trusted local dispatcher. The service owns the Codex session registry, persists provider events, fences duplicate controls, and exposes bounded local wait/history calls.

Verified:

- agentd: 103 tests passed after session actor, internal process bridge and execution-store integration, including real fake-provider subprocess tests.
- agent-bridge-client: 20 tests passed.
- managed_catalog real iroh test: 1 passed, including explicit sharing and snapshot/replay.
- legacy transport: 10 passed, 2 real-Codex tests intentionally ignored.
- host_restart: 3 passed when run serially; initial parallel run hit the existing UDP-port release timing race.
- iOS arm64 simulator build passed. Generic universal simulator build failed because the existing XCFramework does not contain x86_64; arm64 matches the supported build script.
- Device and simulator Rust libraries regenerated by scripts/ios-build-client.sh.

Still required before the product acceptance criteria are met:

- Add ABP request/response routing for the managed command methods and wire typed iOS/desktop client calls.
- Add live client reducers/cache recovery, approval UI and desktop chat surface; storage/runtime send path is now exercised by a deterministic fake-provider integration test.
- Add live subscription owner, client reducer/cache recovery and paginated history.
- Replace the managed iOS chat path and build desktop chat UI/local application actions.
- Validate full phone/desktop chat, approvals, interruption, offline completion and restart recovery.

Managed execution, bounded wait/replay, history pages and approval APIs are now advertised with explicit capabilities. Live delivery is implemented as durable cursor wait/replay rather than an unbounded push stream. The task remains in_progress until final iOS tests and full regression are recorded.

Known validation limits: production builds report unused internal runtime/execution APIs until application integration lands; third-party netwatch also retains existing deprecation warnings. No end-to-end phone/desktop shared chat has been claimed or enabled.
