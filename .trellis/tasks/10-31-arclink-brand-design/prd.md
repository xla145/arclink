# ArcLink · 弧连：命名与 Logo 设计

## 目标
为当前 Agent Bridge 的 macOS 与手机端应用建立统一、易识别的名称与应用图标。跨设备连接 AI Agent 是本轮设计的工作假设。

## 提议方向（待评审）
- 英文名：ArcLink；中文名：弧连。
- 含义：Arc 表示弧线与桥，Link 表示设备、用户与 AI Agent 的连接。
- 核心标识：两段粗细一致、端点圆润的弧形相扣，通过中央负空间暗示 A；小尺寸时优先保证轮廓清晰。
- 主色：深靛蓝 #171C38；强调色：青色 #50E3D4 与蓝色 #568BFF；单色版使用纯黑或纯白。
- 图标中不放文字，名称独立排版。风格简洁、克制，避免细碎网络节点和复杂高光。

## 交付范围
- 名称与含义说明。
- 主标识、单色标识及 Mac / 手机应用图标视觉稿。
- 可编辑 SVG 与 1024 × 1024 PNG，附 32 / 64 像素辨识预览。
- 一页品牌预览，包含浅色和深色背景效果。
- 用户追加授权：将品牌接入 Mac 与 iOS 应用，更新显示名称、应用图标与界面品牌；保持 bundle ID、Rust 包名、协议和数据路径兼容，不发布应用。名称尚未进行商标或应用商店重名核查。

## 验收标准
- 英中名称在交付物中一致。
- Mac 与手机端使用同一核心标识；手机端底图满幅，圆角由系统处理。
- 32 像素预览中主体轮廓可辨识，单色版保留同样的识别结构。
- SVG 可编辑，PNG 尺寸正确，无水印或意外文字。
- 主方案与预览资产保存于工作区并提供路径。
