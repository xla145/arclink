# Design and frozen contract

Keep iroh and opaque host. Add capabilities io_resume_offsets_v1, io_lease_replace_v1, io_ndjson_records_v1 through GetCapabilities. StreamOpen optional IoResume (tag5) with stdout_offset, stderr_offset, previous_lease_id; bool record_framed(tag6). Initial Codex attach uses new client attachChatIo; original raw attachIo unchanged. Open response returns lease_id. Client exposes IoHandle.leaseId() -> String and BridgeConnection.resumeChatIo(processId,generation,stdoutOffset,stderrOffset,previousLeaseId,callback). Both chat APIs negotiate capabilities; old host must not silently ignore resume/record fields.

Host validates peer/task+approval/owner/generation and offsets. Replace only matching prior lease, old session Drop must not clear new lease, old queued input fenced. Atomically snapshot offsets/ring and filter overlapping chunks, per-channel explicit gaps including fully evicted channel. Allow resume of exited retained process to drain then authoritative exit. Maintain bounded 4MiB ring (larger than prior64KiB for image echoes); native NDJSON input records <=2MiB, buffer per stream and forward only complete newline-terminated record; discard incomplete upload on detach. Never change raw terminal byte semantics.

Swift CodexChatSession owns image input and attach epochs/checkpoints, keeps partial NDJSON buffer and request correlation across recoverable network error. Feed ordered events with byte offsets; advance checkpoints only as accepted. On stream network error detach writer but retain protocol state; bounded recovery API reattaches same process (no initialize/replay). Typed events recoveryNeeded/recovered as needed; reconcile state only using read-only native thread/read if needed. Unknown writes/approvals never auto replay. Add active-turn snapshot support for thread/resume so app restart cannot send duplicate turn while one is active. Terminal/raw remains separate.

Image encoding boundary: UI/store helper prepares valid JPEG, maximum4, <=256KiB each and <=1MiB combined binary. Codex send(text:images:) creates image data URLs; line max2MiB. iroh frames remain16KiB, native JSON may exceed1MiB as stream of frames. User images stay device-scoped locally. AppStore captures original device/session, owns single-flight foreground recovery (exponential capped retry; trigger after host health and foreground). Views expose recovery progress/retry and enable picker/paste. Driver and UI changes preserve test injection.

Ownership: Rust worker owns protocol/host/client/harness/tests. Swift protocol worker owns CodexChatSession and its tests. UI worker owns AppModel/ChatView/image helper/store tests. Root owns generated FFI build, docs and integrated validation.
